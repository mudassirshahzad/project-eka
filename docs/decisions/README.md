# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Project EKA.

ADRs document significant architectural decisions — the context, the options considered, the decision made, and the consequences. They are written at the time of the decision and are immutable after that point.

ADRs for Project EKA are recorded in two places, not as individual files in this directory:

- [`.claude/DECISIONS.md`](../../.claude/DECISIONS.md) — full prose ADRs (context, decision, rationale), grouped under a per-milestone heading. Append-only; never edited retroactively.
- [`.claude/PROJECT_STATE.md`](../../.claude/PROJECT_STATE.md) — the "Frozen ADRs" table also carries the G-series (Generation/Retrieval pipeline) ADRs as single-line entries.

Check both — an ADR code not found in one is likely in the other.
